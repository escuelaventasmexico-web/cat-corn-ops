## Comportamiento Interactivo

### Al cargar el detalle del socio:
1. Se renderiza el componente `CommercialB2BSummary`
2. Inicia carga de datos (loading = true)
3. Muestra spinner + "Cargando resumen comercial..."
4. Realiza 2 queries paralelas:
   - `v_commercial_partner_operational_summary`
   - `v_commercial_partner_wholesale_summary`
5. Si error: muestra tarjeta roja con mensaje
6. Si data: calcula totales y renderiza tarjetas
7. Si no hay data: retorna `null` (no muestra sección)

### Al hacer scroll en el drawer:
- Las tarjetas se desplazan suavemente
- Layout responsive se mantiene
- Estilos consistentes con el resto
